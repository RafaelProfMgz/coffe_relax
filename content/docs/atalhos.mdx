---
title: Atalhos de teclado
description: Notas afinadas nas teclas do vim.
---

O **Teclado do Café** toca notas de uma escala pentatônica, então qualquer sequência soa bem. Dá para clicar nas teclas da tela ou usar o teclado de verdade.

| Tecla | Nota |
| :--- | :--- |
| `h` | dó |
| `j` | ré |
| `k` | mi |
| `l` | sol |
| `w` | lá |
| `b` | dó (oitava acima) |
| `espaço` | nota grave |

## Quando os atalhos funcionam

- Só depois do clique na tela de abertura, que acorda o áudio.
- **Não** quando o cursor está num campo de texto (link da playlist, notas do mural), para não atrapalhar a digitação.
- **Não** com **Ctrl**, **Alt** ou **⌘** apertados, para não roubar os atalhos do navegador.

Cada tecla tocada pisca o indicador do topo para `-- INSERT --`, uma piscadela para quem vem do vim.
